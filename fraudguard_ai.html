What We Built

Complete ML Development
Life Cycle

10 experiments covering every stage from problem definition to live deployment of a production fraud detector.

🎯

Problem Definition

Binary classification — fraud (1) vs legitimate (0) — with well-scoped input features and target variable from Indian transaction data.

🔍

Exploratory Data Analysis

Deep dives into class imbalance, distribution plots, correlation heatmaps, and category-wise fraud rates across merchant types and cities.

⚙️

Feature Engineering

Extracted transaction hour and month from timestamps, one-hot encoded categoricals, and applied StandardScaler on numerical features.

🌲

Random Forest Classifier

Trained Logistic Regression, Decision Tree, and Random Forest. RF won on recall and F1 — critical for catching fraud without overwhelming false positives.

🎛️

GridSearchCV Tuning

Hyperparameter grid search over n_estimators, max_depth, min_samples_split, and class_weight for optimal fraud recall performance.

🚀

Live Deployment

End-to-end predict_fraud() function handles encoding → scaling → prediction in one call. Returns probability, risk tier, and confidence.
